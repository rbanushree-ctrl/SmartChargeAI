# SmartCharge AI
### Intelligent EV Charger Sharing Platform

## About the Project
SmartCharge AI is a web-based platform that connects electric vehicle (EV) owners with homeowners who have available EV charging facilities.

The platform allows homeowners to share their chargers and enables EV users to discover, compare and book nearby charging facilities.

## Key Features
- User registration and login
- Homeowner charger registration
- Nearby charger search
- Charger availability and booking
- Intelligent charger recommendations
- Charging demand prediction
- AI-powered conversational assistant
- Analytics dashboard

## Technologies Used

**Frontend:** HTML, CSS, JavaScript

**Backend:** Python, Flask

**Database:** MySQL

**Data Science:** Pandas, NumPy

**Machine Learning:** Scikit-learn

**AI and LLM:** LLM API integration

**UI/UX:** Figma

**Version Control:** Git and GitHub

## Project Team
Developed collaboratively by a team of three members.

## Project Objective
To develop an intelligent EV charger-sharing platform that improves charger accessibility through web technologies, data science, machine learning and AI.
